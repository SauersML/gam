# Issues 2834 and 2828: source corrections, compiled validation pending

## Changes

- **2834:** the value-only Cholesky admission test accounted for the smooth
  spectral floor but not condition-dependent factorization error. Include the
  first-order estimate `2 gamma_n ||H||_F ||H^-1||_F`, where
  `gamma_n = n eps / (1 - n eps)`, in its existing agreement budget. Strong
  penalty matrices use the same spectral kernel as derivative evaluations.
  The terminal agreement audit and smoothing-parameter bounds are unchanged.
- **2828:** the matrix-free adjoint used an aggregate solution Rayleigh quotient
  to decide whether to search for null directions, then projected in the B
  metric. This is not the dense Euclidean spectral pseudoinverse. Generate the
  trial space with `A + sqrt(eps) B`, then diagonalize the projected physical A
  and apply its shared direction floor. Resolve numerically repeated A
  eigenspaces in B on both representations. Expand unresolved physical or
  metric directions when the generating Krylov space ends early. Require
  machine-roundoff backward accuracy to retain responses to weakly excited
  band modes. Include positive and negative resolved modes, within an explicit
  live-memory budget. Correct the dense normal-equation certificate to use the
  projected RHS, so an entirely discarded RHS has its valid zero response.
- The exact beta-curvature and frozen-gate corrections for item 1 of 2828 are
  already present in the base revision. Their finite-difference tests remain.

## Evidence and limits

No compilation was performed, following the user's instruction. No GitHub
Actions validation was dispatched. These changes have **not** passed compiled
Rust regressions or the public Gaussian acceptance test. Neither issue should
be closed on this evidence alone.

Independent NumPy reproductions ran on MSI acn112, pinned to one sampled idle
CPU at nice 19, with numerical thread pools limited to one. Their source is in
`/projects/standard/hsiehph/sauer354/gam-issues-2834-2828/verify_math.py` and
`verify_adaptive.py`, and `verify_block.py`. They are mathematical probes, not executions of the
changed Rust implementation.

- Null-only, mixed, weak null excitation, noncommuting B, signed retained
  modes, an entirely discarded spectrum, and a gapless null cluster passed.
- Thirty adaptive spectral-action cases with dimensions 3–64, diagonal and
  rotated spectra, and band excitation of 1, sqrt(eps), and 1e-10 passed.
  Worst relative disagreement with dense NumPy solves: **2.830e-8**.
- The revised metric-augmented construction passed **43 cases**, including
  repeated A eigenspaces with split B scales, rotated B eigenspaces, a scalar
  generating operator hiding non-scalar A, and the earlier null-space cases.
  Worst relative disagreement with the dense reference: **6.869e-8**.
- For rotated spectra `[1, 2, 3, strength]`, the factorization estimate was
  `1.161e-14`, `2.072e-5`, and `2.072e-3` at strengths 4, 1e10, and 1e12.
  Against the existing agreement envelope, the benign case is admitted and
  the two strong-penalty cases are declined.
- The pre-existing installed MSI extension failed the public Gaussian seed-0
  test in 12.66 seconds. That binary predates these edits; this is baseline
  evidence only and does not validate the correction.
