# Issues 2828 and 2834: MSI validation, 2026-09-10

## Exact-A (#2828)

The dense and matrix-free stationarity solves now share an ordinary Euclidean
spectral pseudoinverse, including the direction-dependent B floor and repeated-A
eigenspaces. The matrix-free trial space uses A + sqrt(eps) B, with physical-A
projection, metric leakage expansion and machine-roundoff residual certificates.
The dense normal residual uses the projected RHS, including a wholly null RHS.

The base revision already contained the frozen-gate and exact beta-curvature
corrections. Executable validation exposed another live defect: beta motion of
the exact-A log determinant omitted residual-curvature third derivatives, the
three decoder priors' third derivatives, and the explicit beta derivative of
the majorization gap used to price negative directions. These terms now reach
dense, selected-inverse, probe and resident row-jet contractions. The priced
negative-subspace inverse supplies the additional border-gap contraction.

Separation curvature's overlap-space majorizer is a Gram matrix because the
floored spectral derivative G = V diag(m'/m) V^T is PSD, even for indefinite F.
It is retained directly, removing an unnecessary eigenvalue-absolute-value
reconstruction and its cubic cost. Both its derivative and the exact prior
derivative have independent finite-difference checks. The amplitude assembly
test now includes its structured smooth-block storage. The converged-mode test
checks the actual exact Hessian; it no longer requires a reconstructed historical
operator to reproduce a negative eigenvalue at an optimizer-dependent endpoint.

Native Rust tests on MSI acn112, four sampled idle CPUs, nice 19:

- Eight null-space policy cases and the gapless-cluster regression passed.
- The production Patch-D classification-band fixture passed column-by-column
  dense/matrix-free A equality and both stationarity solves, including a RHS
  concentrated on the weakest retained mode.
- The dense exact-A versus KKT-gradient finite difference passed.
- Six decoder-prior curvature tests passed, including independently measured
  prior values, assembled majorizer and nonnegative curvature at the fitted mode.
- Three beta-adjoint tests passed. The full priced logdet beta derivative's
  worst relative error, including its FD oracle error, fell from 1.711 to
  **4.885e-10** across 12 coordinates. Exact and majorization-gap prior trace
  derivatives passed across all 18 beta coordinates. Resident/dense softmax
  parity was within **4.263e-14** on beta for exact A.
- Two CPU row-jet trace regressions passed, including the existing finite-
  difference test. The matching CUDA beta kernel argument list and contraction
  were updated; device execution has not been checked.

These are **22 distinct passing native crate tests**. The nine prior/adjoint
tests took 53.70 seconds, and the 12-test operator/row-jet group took 42.69
seconds (the gapless case passed in an earlier group). Full SAE test compilation
used Rust 1.97.1, warnings denied, opt-level 1 and the current Cargo graph's warm
dependencies. No builds or tests ran locally and no GitHub Actions jobs were
dispatched. Every subprocess had a deadline and used disk-backed shared/scratch

The matrix-free global scale uses an independent Lanczos estimate; these gates
do not establish a deterministic global norm bound for every possible operator.

## Gaussian factor smooths (#2834): additional validation in progress

The ordinary unconstrained Gaussian route already uses the spectral operator
for every evaluation order (`bceafaf17`, integrated through `d42c4232f`). The
additional Cholesky admission guard in `b302d746c` applies to the other dense
route and accounts for condition-dependent factorization error. It leaves the
terminal audit and rho limits unchanged.

A current-source Python extension built on MSI exposed a terminal stationarity
failure on seed 3: gradient 1.366e-5 against bound 1.145e-5. The scalar root-scale
logdet upgrade left solves and derivatives on the assembled spectrum. The
complete spectral operator now uses root-SVD eigenpairs, including inverse,
gradient and Hessian. Its penalty roots must come from the fitted bundle's
applied canonical penalties: the raw canonical penalties precede the balanced
projection and did not reconstruct the fitted Hessian. Commit `7296166fc` fixes
both inconsistencies without changing the audit or rho limits.

Five native tests passed in 1.19 seconds: two root-logdet tests (including an
ill-conditioned analytic logdet/inverse/gradient/Hessian oracle) and three
lane-agreement tests. Public seeds 0, 2, 3, 6, 7, 10, 11, 12 and 16 passed with
extension SHA-256
`dec5c69f40b3b05477b680635db8a461ff6a7b48a4a983637a91397478a30590`.
The first eight were run in one 120-second bounded batch, stopped during the
next case; seed 16 passed in a separate run.

Seed 17 then exposed a post-optimization covariance failure: cubature recomputed
a resolvability domain independently of the fitting domain, so its accepted
mode could be outside the integration box and leave zero proposal width. The
standard REML caller now passes its fitting domain into covariance calculation;
the independent accessor is removed. All eight covariance tests pass, including
the full response-scale-equivariance regression (1.92 seconds). Public Python
validation of this last correction is pending. **Do not close #2834 yet.**
