# sample-rho-marginal

TITLE: Non-Gaussian sample() must integrate smoothing-parameter uncertainty exactly like predict() does
WORK ITEM: Read audit/inference.md G3 and the sample study (bench/pygam_audit/inference/mc_sample.py, mc_sample_stream.py, sample_summary.py, tables_binom.md).
Evidence: binomial sample() reports method "polya-gamma" with covariance_source "conditional". Its mean-interval coverage is 0.912 vs 0.947 for predict() on the same fits (paired difference +0.035, SE 0.009), and predict() intervals are 1.15x wider. So draws condition on rho_hat while the default predict() band is smoothing-corrected. Gaussian sample() is fine (0.967; pyGAM 0.916). pyGAM's own sample() bootstraps 5 times over a random lambda grid, which is slop we do not copy.
Fix: make sample() for every family draw from the rho-marginal posterior. Draw rho from the same cubature nodes and weights that the smoothing correction already builds (crates/gam-solve/src/reml/eval.rs; expose them from the fit payload rather than recomputing), then draw beta exactly given each rho (Polya-Gamma for binomial, the existing exact samplers elsewhere). This needs no importance weights, because the nodes carry the weights; allocate draws to nodes by stratified multinomial on the weights so the Monte Carlo error is minimal, deterministic under the seed. Report covariance_source "smoothing_marginalised" and the node count. When the smoothing correction itself fell back (see smoothing-correction-provenance), inherit its typed reason rather than silently conditioning. Delete the conditional-only default path if nothing else needs it (SPEC: delete unnecessary options). Logic in Rust; Python stays thin.
Coordinate: smoothing-correction-provenance (the cubature outcome and reason), rho-uncertainty (the corrected covariance for many rho), firth-rescue-transparency (same sampler files), lazy-postfit (do not add an eager post-fit cost; compute the nodes lazily if that lane made them lazy).
Acceptance:
- A seeded simulation test (binomial and Poisson, n=400, at least 200 reps; tolerance from the Monte Carlo SE, no magic numbers) asserts that sample()-based 95% mean intervals cover at nominal and agree with predict() intervals to within MC SE.
- A unit test asserts that the empirical rho distribution across draws matches the node weights.
- Both fail at HEAD. Report coverage and time per 1000 draws vs pyGAM sample() in the PR.
