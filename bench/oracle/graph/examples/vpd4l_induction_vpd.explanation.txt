When a stretch of text repeats, the model predicts the token that followed the current token in the first copy, using a small set of attention subcomponents in each layer. Layer 1's attention is the previous-token step: one query subcomponent and one key subcomponent, each indispensable, make it look one position back, so each position records the token before it. Layer 2's attention is the induction step: its key reads layer 1's record, its query asks for the current token, so it finds the position after the earlier copy and its value and output subcomponents copy that token out. Layer 3's attention reads layer 2's output through its value and writes the same token again. Layer 0's attention subcomponents also matter, and the program lets their output reach the later layers without claiming a role for them; the MLP subcomponents are left as they are on the edited prompt.
