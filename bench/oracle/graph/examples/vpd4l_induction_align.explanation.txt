The model copies the token that followed the current token the last time it appeared. Layer 1's attention looks one position back, through one query and one key subcomponent (316 and 329), and its value and output subcomponents write, at every position, which token came just before it; that record is the variable prev. Layer 2's query and key subcomponents (335 and 206) compare the current token with prev, so layer 2 attends to the position right after the earlier copy of the current token. Its value and output subcomponents (559, 735) copy the token found there into the prediction, and layer 3's value and output subcomponents (677, 806) write the same token again. Swapping prev from another prompt changes the prediction to whatever followed the current token in that prompt.
