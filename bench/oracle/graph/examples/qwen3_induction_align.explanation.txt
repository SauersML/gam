The model copies the token that followed the current token earlier in the text, in two stages that work the same way. Previous-token heads (L1.H3 and L2.H12 early, L15.H3 and L20.H0 late) look one position back and write, at every position, which token came just before it: the variable prev. Induction heads (L3.H10 early, L16.H14 and L21.H8 late) compare the current token with prev, attend to the position right after the earlier copy of the current token, and copy the token found there into the prediction; L21.H8 matters most. Swapping prev from another prompt makes the induction heads copy whatever followed the current token in that prompt.
